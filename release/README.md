# release/

- `release-manifest.template.json` — the committed "no release yet" manifest shape consumed by the landing build (status `pending`). The landing shows the truthful "Download not available yet" state for anything but `status: "released"` with valid fields.
- `dist/` — generated by `scripts/release/build.sh <version>` (archive, `.sha256`, `release-manifest.json`, `release.json`, guides). Generated output; keep it out of Git (orchestrator: add `release/dist/` to `.gitignore`).

Build, verification and publication rules: `docs/release.md`.
